# Release History

## 0.1.0 (Unreleased)

### Features Added

- Initial preview of the `azure.springboot` extension (`host: springbootapp`) for packaging and deploying Maven and Gradle Spring Boot applications to Azure Container Apps, including multi-module Maven projects, database-free and H2 services, Entra-authenticated PostgreSQL reconciliation (single- and multi-database), and Spring Cloud Config Server import handling.
